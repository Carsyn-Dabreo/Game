# CyberGrid - Cybersecurity Training Simulation

A full-stack cybersecurity training simulation built with React Three.js, Node.js, PostgreSQL, and AI integration.

## 🏗️ Architecture

```
Frontend (React + R3F)
        ↓
Backend (Node.js + Express)
        ↓
Database (PostgreSQL)
        ↓
AI API (GPT-4o / Gemini)
        ↓
Realtime (Socket.IO)
```

## 🚀 Features

- **Immersive 3D Environment**: Post-apocalyptic city with realistic graphics
- **AI-Powered Challenges**: Dynamic cybersecurity challenges generated by GPT-4o or Gemini
- **Real-time Multiplayer**: Socket.IO powered real-time interactions
- **Progress Tracking**: Comprehensive user progress and achievement system
- **Leaderboard**: Competitive scoring system
- **Responsive Design**: Works on desktop and mobile devices

## 📋 Prerequisites

- **Node.js** 18+ 
- **Docker** & Docker Compose
- **PostgreSQL** (handled by Docker)
- **AI API Key** (OpenAI or Google Gemini)

## 🛠️ Quick Start

### Option 1: Automated Setup (Recommended)

**Windows:**
```bash
setup.bat
```

**Linux/macOS:**
```bash
chmod +x setup.sh
./setup.sh
```

### Option 2: Manual Setup

1. **Clone the repository**
```bash
git clone <repository-url>
cd cybersec-game
```

2. **Setup Backend**
```bash
cd server
npm install
cp .env.example .env
# Edit .env with your API keys
cd ..
```

3. **Setup Frontend**
```bash
npm install
# Create .env if needed
echo "VITE_API_URL=http://localhost:3001" > .env
echo "VITE_SOCKET_URL=http://localhost:3001" >> .env
```

4. **Start Database**
```bash
docker-compose up -d db
```

5. **Start Development Servers**
```bash
# Terminal 1 - Backend
cd server
npm run dev

# Terminal 2 - Frontend
npm run dev
```

## 🔧 Configuration

### Environment Variables

**Backend (server/.env):**
```env
# Server
PORT=3001
NODE_ENV=development
CLIENT_URL=http://localhost:5173

# Database
DATABASE_URL=postgres://cyber:grid_secret@localhost:5432/cybergrid

# Authentication
JWT_SECRET=your-super-secret-jwt-key
JWT_EXPIRES_IN=7d

# AI Services (choose one or both)
OPENAI_API_KEY=your-openai-api-key
GEMINI_API_KEY=your-gemini-api-key
```

**Frontend (.env):**
```env
VITE_API_URL=http://localhost:3001
VITE_SOCKET_URL=http://localhost:3001
VITE_APP_TITLE=CyberGrid
```

### AI API Setup

**OpenAI GPT-4:**
1. Go to [OpenAI Platform](https://platform.openai.com/)
2. Create an API key
3. Add to `server/.env`: `OPENAI_API_KEY=sk-...`

**Google Gemini:**
1. Go to [Google AI Studio](https://aistudio.google.com/)
2. Create an API key
3. Add to `server/.env`: `GEMINI_API_KEY=...`

## 📊 Database Schema

The application uses PostgreSQL with the following main tables:

- **users**: User accounts and statistics
- **challenges**: AI-generated and static cybersecurity challenges
- **scores**: Game scores and leaderboard data
- **progress**: User challenge progress and attempts
- **achievements**: User achievements and unlocks
- **user_sessions**: Real-time session tracking

## 🔌 API Endpoints

### Authentication
- `POST /api/auth/register` - Register new user
- `POST /api/auth/login` - User login
- `GET /api/auth/verify` - Verify token

### Challenges
- `GET /api/challenges` - Get all challenges
- `GET /api/challenges/:id` - Get specific challenge
- `POST /api/challenges/generate` - Generate AI challenge
- `POST /api/challenges/:id/attempt` - Submit answer
- `GET /api/challenges/:id/hint` - Get hint

### Scores
- `GET /api/scores/leaderboard` - Get leaderboard
- `GET /api/scores/history` - Get user history
- `POST /api/scores` - Submit score

### Progress
- `GET /api/progress` - Get user progress
- `GET /api/progress/achievements` - Get achievements
- `GET /api/progress/recommendations` - Get AI recommendations

## 🔄 Real-time Events

Socket.IO events for real-time features:

- `join-game` - Join game session
- `challenge-attempt` - Attempt challenge
- `score-update` - Update score
- `player-movement` - Player position updates
- `leaderboard-update` - Leaderboard changes

## 🆘 Troubleshooting

### Common Issues

**Database connection failed:**
- Ensure Docker is running
- Check if PostgreSQL container is up: `docker-compose ps`
- Verify database URL in `.env`

**Frontend not connecting to backend:**
- Check if backend is running on port 3001
- Verify CORS settings
- Check API URL in frontend `.env`

**AI API errors:**
- Verify API keys are correct
- Check API quotas and billing
- Ensure network connectivity

**Socket.IO connection issues:**
- Check if Socket.IO server is running
- Verify CORS configuration
- Check firewall settings

### Getting Help

- Check the logs: `docker-compose logs -f`
- Review browser console for frontend errors
- Check backend console for API errors
- Ensure all environment variables are set correctly
